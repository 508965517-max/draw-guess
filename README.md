# 你画我猜 · 随时可玩版

纯静态、点对点（P2P）的多人联机"你画我猜"小游戏。无需后端服务器、无需信用卡，托管在 GitHub Pages 上**永远在线**，手机 / 电脑随时打开即玩。

## 玩法
- **单人模式**：只有你和机器人，轮流作画 / 猜词（可选机器人性格：话痨型 / 秒猜型）。完全离线可玩。
- **创建房间（多人）**：纯多人，不会有机器人。把 4 位房间号发给朋友，朋友在首页输入房间号即可加入。
- **加入房间**：输入朋友给的房间号进入。

> 多人模式采用房主客户端当"主机" + PeerJS 直连：房主的设备在游戏期间需保持在线；网站本身（GitHub Pages）永远在线，随时可进入。

## 本地运行
```
node serve.js
# 然后浏览器打开 http://localhost:3000
```
或直接双击 `start.bat`。

## 技术
- 前端：HTML5 Canvas + PeerJS（WebRTC 信令由 PeerJS 公共 broker 提供）
- 游戏权威逻辑运行在"房主"浏览器端，其余玩家通过 DataConnection 直连同步
- 部署：GitHub Pages（仓库根目录，`main` 分支）
